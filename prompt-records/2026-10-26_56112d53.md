> **Policies**
> - `profiles`: select is public (`anon` and `authenticated`, `using (true)`). Update is own row only.
> - `library_items`: select, insert, update and delete are `authenticated` only, with `(select auth.uid()) = user_id`. There is no anon access.

> **PostgREST join for logs with display name:** `logs.user_id` has a direct FK to `profiles`, so this works:
> ```js
> supabase.from('logs')
>   .select('id, body, rating, created_at, updated_at, user_id, profiles(display_name)')
>   .eq('volume_id', id)
>   .order('created_at', { ascending: false })
> ```
> - `logs` has two FKs, one to `profiles` and one composite to `library_items`. Embedding `profiles` is unambiguous. Don't embed `library_items`, because RLS would hide other users' rows.
